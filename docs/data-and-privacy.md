# 数据与隐私说明

这份说明给教师、试用组织者和维护者使用。它描述当前可观察的边界，不替代学校/机构的隐私政策、DPA、儿童保护规则或法律意见。

## 我们建议课堂只收集什么

最低数据集是：匿名试用编号、练习页面/技能、操作是否成功、用户主动填写的匿名反馈和技术问题描述。不要为了验证界面收集姓名、邮箱、学号、身份证件、住址、健康信息、密码、token、完整个人作文、他人信息或真实录音。

如果需要展示文本，优先使用预设演示夹具或经过明确同意、去标识且最小化的片段。课堂演示中的文本不代表真实学生成果。

## 当前存储边界

### 浏览器本机

草稿、历史快照、复盘 notes、标记、错因和阅读标注可能存在浏览器 localStorage 或页面状态中。当前产品新写入使用服务端验证账号的本机 namespace；受保护页面打开后若浏览器会话在另一标签页退出或切换账号，页面会先隐藏并重新验证，不会在旧页面内接受新账号。本机存储仍不是账号隔离数据库：退出或切换账号不自动删除旧本机数据，也不能保证另一个用户看不到同一浏览器留下的内容。因此：

- 共享电脑不要保存真实学生作答；使用隔离浏览器/访客会话和匿名夹具。
- 切换账号前先停止，确认本机数据归属；不要自动把旧数据上传给新账号。
- “清除当前目录草稿/标注”不等于删除 history、账号数据或远程数据；清理前阅读范围和失败反馈。
- 配额、权限、坏 JSON 或局部写入失败时，应保留当前输入并提示重试，不能宣称“全部已保存”。

### 录音与语音

Speaking 录音若可用，是当前浏览器内存中的 Blob/对象 URL。它不会自动随 history 保存，也没有默认的云端恢复、跨设备访问或永久删除承诺。课堂默认不使用真人麦克风；如要使用，需另行取得知情同意、说明保存周期和访问者，并确认浏览器权限。

占位音轨、浏览器 TTS 或 synthetic speech 仅为产品流程演示，不是官方录音或真人朗读。合成语音可能依赖设备/厂商服务，不能用来证明发音、听力能力或学生效果。

### Supabase/云端

云端能力由独立配置和 RLS 决定，默认不应后台上传。历史备份是手动操作；标注同步在明确授权、成功建立远端基线后，会自动上传后续新增、编辑和删除，直到暂停或授权失效。暂停不能撤回已发送的请求。任何一次同步成功，都不自动代表：

- 所有本机历史都已上传；
- 另一台设备能恢复所有文本；
- 录音 Blob 已保存；
- 账号切换后的旧数据被正确隔离；
- 远程冲突、部分失败或陈旧数据已解决。

内容表读取需要有效认证会话；仅用 publishable/anon key 可能读到空集。不能用关闭 RLS、service-role key 放前端或静默回退样例来绕过问题。服务角色密钥只能由管理员在受控服务端使用，不能进入浏览器、日志、截图或仓库。

## 启用真实试用前必须填好的责任与期限

当前没有在此核实学校、隐私负责人或保存期限，不能编造默认的“30 天已自动删除”等承诺。未填全前，只做不含个人数据的隔离演示。

| 待确认项 | 组织者填写 |
| --- | --- |
| 试用组织/负责教师 | 待确认 |
| 隐私/技术问题联系渠道 | 待确认（用机构渠道，不公开个人电话） |
| 反馈表与受同意片段保存位置、可访问角色 | 待确认 |
| 保存目的、截止日期和删除方法 | 待确认 |
| 撤回同意、查阅/更正/删除请求处理者 | 待确认 |
| Supabase 部署区域、机构协议和备份策略 | 待确认 |
| 未成年人/学校课程是否需额外同意 | 待确认 |

本机删除不等于云端删除，退出登录也不等于清理浏览器数据。涉及云端记录的删除请求应交获授权管理员核查 RLS、保留政策与备份范围；不承诺应用已有一键全部删除。

## 最低运维清单

### 试用前

- [ ] 说明收集什么、不收集什么、保存多久、谁能看。
- [ ] 使用隔离测试账号/浏览器，不打开既有认证 profile。
- [ ] 默认关闭 live Supabase、云同步和录音；若有例外，先书面授权并记录范围。
- [ ] 确认演示内容的来源、许可和公开范围；Cambridge 资源未确认前不公开。
- [ ] 准备离线/纸笔退路，避免学生因系统失败丢失作答。

### 试用中

- [ ] 不让学生填写不必要的个人信息。
- [ ] 观察保存成功/失败反馈，不用 HTTP 200 或页面不报错替代数据核对。
- [ ] 学生发现他人数据时立即停止，不截图、不传播，记录最小化技术事实。
- [ ] 不把录音、作文和账号 ID 发到公共聊天或模型服务。

### 试用后

- [ ] 由负责人按事先约定处理本次隔离试用的账号、临时文件和下载目录。既有认证 profile、正式报告和证据产物本轮不删除；未来清理须另外确认范围并获授权。
- [ ] 检查报告/PDF/截图/CI artifact 没有个人数据、profile、cache、`.env` 或版权资源。
- [ ] 记录删除失败、未完成的远程同步和待处理冲突。
- [ ] 只汇总匿名操作反馈，不推导学生成绩或学习提升。

## 发生问题怎么办

1. 先停止操作，不刷新、不清空、不重复提交。
2. 复制当前非敏感文字到机构批准的位置；不要复制 token、cookie、完整账号数据或他人内容。
3. 记录时间、页面、操作和可见错误，不记录密钥或个人信息。
4. 通知指定维护者/隐私负责人；确认是否需要撤下公开 artifact、失效会话或清理本机。
5. 在问题解决前，把该项标为“未验收/未同步”，不要向学生承诺恢复。

## 不应作出的承诺

本项目当前不默认承诺：永久保存、自动云备份、换设备恢复、账号级历史全隔离、录音恢复、官方内容授权、官方评分、AI 判分或学生效果。所有这些都需要单独的实现、权限、协议和证据。
