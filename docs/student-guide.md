# 学生使用指南

## 你今天要做什么

这是一个练习和复盘工具，不是自动给你发官方分数的考试系统。一次练习通常是：读材料或题目 → 作答 → 检查客观题/人工复盘主观题 → 写一条 notes 或目标 → 再决定是否开始新一轮。

老师给你的演示文字不是你的成果。课堂夹具、截图和报告也不代表真实学生成绩。

## 开始前

1. 用老师给的入口登录，不把密码、验证码或个人资料写进题目答案。
2. 确认页面显示的是正确考试和技能。CET 样例不换算 IELTS Band，也不换算官方 CET 分数。
3. 进入练习页面即开始累计本轮用时（恢复草稿时接着已保存的用时累计），阅读材料也计入；当前没有暂停计时按钮。普通练习超过建议时限后仍累计用时，不会自动交卷；查看结果后停止计时。只有“开始限时”模式会在到期时结束作答并尝试保存。刷新或离开会退出限时模式，离页时间不计入练习时长。时间提示是练习辅助，不是官方考试计时。
4. 写作、翻译和口语的参考内容不是唯一答案；系统不会用参考文本逐字判你的质量。
5. 若页面提示浏览器不支持 Web Locks 或本机存储不可用，先不要开始正式长文作答。换用学校认可的近期浏览器和安全入口；不要通过清空已有数据来解决。

## 作答、提交和复盘

- 客观题选择或输入答案后再检查。重复打开、刷新或重复检查不应凭空增加一条练习；如果页面出现异常提示，先停下来保留当前文字。
- 写作/翻译使用完整文本，保留段落和换行。字数提示只表示长度，不是质量评分。
- 提交后可以写本题复盘笔记、错因、标记和自评。它们应该补充同一条练习的复盘，不应改变原来的答案和耗时。
- 每次有效提交有稳定的练习身份。看到按钮不等于保存成功，请等“本机保存状态”明确显示历史与复盘已保存；失败时先保留当前文字。
- 新记录保存完整文本，上限是每题 20,000 字符、每次 200,000 字符；超限会提示，不会悄悄截短。旧历史可能只有最多 400 字符的摘要，已经丢失的部分无法从现在的草稿还原。
- 本机历史最多保留 120 条；它不是长期档案。重要的自己的文字请按学校规定另存，不把本浏览器当作唯一备份。
- 保存失败、读取失败、配额不足或页面显示未保存时，不要刷新来碰运气，也不要清空历史。先把输入复制到你自己的受信任位置，然后请老师/管理员协助。

## “只改一点”再练

提交并确认首稿保存后，写下一个小目标，例如“给建议句补上时间和具体动作”，等目标也保存成功，再点击“带着目标再练”。这条本机流程已通过离线测试和隔离组件浏览器检查；学校正式入口仍须课前复测，不代表云端恢复已可用。

1. 目标会保存为下一轮的目标副本。
2. 开始下一稿会得到新的 attempt，不覆盖首稿。
3. 写作/翻译以当前文本为修改起点；客观题和口语新轮清空答题文字。口语不复制临时音频，也不把上一轮自评当作本轮自评。
4. 详情页应显示父稿关联和前后文字。它不会自动判断目标达成，也不会把变化写成学习提升。

如果你已有另一个未提交草稿，先读清覆盖确认。不要直接用 URL、导入参数或复制粘贴覆盖另一份草稿。父稿缺失、超出历史保留范围或保存失败时，页面应如实提示；不要用相邻时间的一条记录冒充二稿。

## 录音和语音

Speaking 录音若开放，只是当前浏览器的临时内存对象。它可能在刷新、离开页面或清理后消失，不会自动出现在历史记录，也不承诺能在另一台设备恢复。使用前先征得老师和本人同意，不录入姓名、地址或其他人的声音。

听力里的占位音轨或浏览器合成语音不是官方录音，也不保证像真人录音；TTS 不是官方答案或发音证据。麦克风不能用时，用文字要点和人工自评，不要把浏览器报错当作成绩。

## 数据和账号

- 本机草稿、历史和标注可能存在浏览器 localStorage；本机数据不按账号隔离。
- 退出或切换账号不会自动清除旧的本机数据。切换账号前先问老师/管理员，不要把旧记录自动上传给新账号。
- 云同步默认关闭。一个“上传/同步”动作如果存在，只表示该次动作的范围，不表示全部历史、录音或草稿已经可以换设备恢复。
- 不在公共电脑保存个人账号；课堂结束按学校规定退出。是否清除本机练习由老师先确认，清除范围可能只包含当前目录草稿/标注，不代表历史账号数据也被删除。
- 发现别人的姓名、邮箱、答案或录音出现在页面时立即停止并告知老师，不截图、不转发。

## 标注云备份（仅在学校启用后）

默认只保存本机。若材料区出现“标注云备份”，先看当前账号和本机保存状态：

- **恢复云端标注**会用该账号此单元的备份替换本机标注；确认前先保留需要的本机笔记。
- **上传本机标注**会替换当前账号此单元的云端标注。空白集合也可能清空云备份，不要为了消除提示随意确认。
- 本机与云端不同、归属不明或保存失败时，先看提示再选择；“等待选择”“同步未完成”都不等于备份成功。
- 启用后，后续新增、编辑和删除会同步。**暂停同步，保留本机**不清理数据，也不能撤回已经发送的请求。
- “清理本机草稿与标注”先暂停同步，不等于删除云端备份；需要恢复时仍要明确选择，不会把本机清理当作云端删除命令。

这套操作不提供整份历史下载恢复，也不保存录音。旧云备份格式不兼容时请联系管理员，不能靠反复上传覆盖来修复。

## 你可以提出的反馈

请用匿名方式描述：哪一个页面、做了什么、页面显示什么、你原本期待什么。不要发送密码、token、完整个人作文、录音或账号 ID。可以说“保存提示不清楚”“刷新后找不到刚才的文字”“目标入口没有反应”，不必给出真实身份。

## 你不需要相信的说法

“上传后任何设备都能恢复”“私有桶就自动合法”“Cambridge 来源就是授权”“占位音频是真人朗读”“AI/系统判定我提升了”“相邻的两条记录就是首稿和二稿”都不是默认事实。需要看到对应的权限、实现和验收证据，老师会告诉你当前试教采用的是哪一个边界。
